🎮 Test API v3 - Endpoint Visual HTML

Prueba el nuevo endpoint /ask-visual-html que devuelve gráficos directamente en el navegador.

📋 Ejemplos de preguntas:

  • games by platform
  • top 10 games by rating
  • games released in 2023
  • most popular genres
  • What is the rating of Cyberpunk 2077?

ℹ️ Cómo funciona:

  1. Escribe una pregunta sobre videojuegos en inglés
  2. Haz clic en "Ver Gráfico"
  3. Se abrirá una nueva pestaña con el gráfico interactivo
  4. El gráfico ocupará toda la pantalla sin información de debug
